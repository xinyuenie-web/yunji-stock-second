# 云基公司二次股权激励管理系统

本项目是云基公司 2024 年**二次股权激励计划**的配套管理系统，提供激励对象管理、股份授予记录、归属计划跟踪及行权登记等功能。

## 功能模块

| 模块 | 说明 |
|------|------|
| **总览** | 展示激励人数、授予股份总量、已归属股份、已行权股份等关键指标，以及各部门激励分布和归属进度 |
| **激励对象** | 激励对象名册的增删改查，支持按部门、激励级别、姓名/工号搜索筛选 |
| **授予记录** | 查看激励计划基本信息（董事会日期、股东大会批准日期、行权价格等）及各对象的股份授予明细 |
| **归属计划** | 三期归属计划卡片展示（第1年末30%、第2年末30%、第3年末40%），以及个人归属明细进度 |
| **行权记录** | 登记和查看员工行权申请，汇总已完成行权股份总量及行权金额 |

## 激励计划基本参数

- **计划名称**：云基公司 2024 年二次股权激励计划
- **董事会审议日期**：2024-03-15
- **股东大会批准日期**：2024-04-10
- **授予日期**：2024-05-01
- **行权价格**：12.50 元/股
- **有效期**：4 年（自授予日起）
- **归属安排**：第 1 年末归属 30%，第 2 年末归属 30%，第 3 年末归属 40%
